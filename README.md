# مين فاضي دلوقتي؟ 🙋

موقع بسيط بيحل مشكلة "مين فاضي نخرج؟" الأزلية - بدل ما تستنى ردود في جروب الواتساب، كل واحد في شلتك بيضغط زرار لما يكون فاضي فعلاً، والكل بيشوف الحالة لايف ومباشر.

## المميزات
- إنشاء "أوضة" خاصة بكل شلة، بلينك تشاركه معاهم
- تحديد إنك فاضي لمدة معينة (بتنتهي تلقائيًا)
- كتابة إيه عايز تعمله (قهوة، أكل، مشوار...)
- تنبيهات المتصفح لما حد يبقى فاضي
- إحصائية "الأكتر فضا في الشلة" 🏆
- تحديث لايف بين كل الأجهزة عن طريق Firebase Realtime Database

## الأدوات المستخدمة
HTML, CSS, Vanilla JavaScript + Firebase Realtime Database (للتخزين المشترك اللايف)

## لو عايز تشغّله بنفسك
1. اعمل مشروع Firebase مجاني من [console.firebase.google.com](https://console.firebase.google.com)
2. فعّل Realtime Database (Test mode)
3. سجّل تطبيق ويب وخد بيانات `firebaseConfig`
4. حطها في `script.js` بدل الـ placeholders
5. ارفع الملفات على GitHub Pages أو أي استضافة ثابتة
